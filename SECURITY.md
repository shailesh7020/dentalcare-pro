# DentalCare Pro - Security Policy & Vulnerability Disclosure

DentalCare Pro processes Sensitive Personal Information and Protected Health Information (PHI). We take the security of our platform and patient records extremely seriously.

---

## 1. Supported Versions

| Version | Supported | Security Patches |
| :--- | :---: | :--- |
| **1.0.x (Enterprise)** | ✅ Yes | Active Security Maintenance |
| < 1.0.0 | ❌ No | End of Life (Development Pre-release) |

---

## 2. Reporting a Vulnerability

If you discover a potential security vulnerability in DentalCare Pro:
1. **DO NOT** disclose the vulnerability publicly or in open GitHub issues.
2. Email full technical details and proof-of-concept steps to: **security@dentalcarepro.com**.
3. You may encrypt your report using our security PGP key.

---

## 3. SLA & Disclosure Policy
- **Acknowledgment**: Within 24 hours of report receipt.
- **Initial Triage & Assessment**: Within 48 hours.
- **Critical Remediation Patch**: Released within 7 business days.
- **Coordinated Disclosure**: 90 days after patch release or by mutual agreement.
